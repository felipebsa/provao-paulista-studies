# Official exams

[Português](README.pt-BR.md)

Past Provão Paulista Seriado exams, published by Seduc-SP and Fundação Vunesp. Each year has a main application and an extra one (for students who missed the first date), and each application has two booklets: booklet 1 is Languages + Natural Sciences, booklet 2 is Mathematics + Human Sciences.

The PDFs from Química para o Vestibular have the official answer key on the last page. The answer key links are the official Vunesp files.

## Folder layout

Each file goes in `exams/<year>/<grade>/` with the name in the table. Example: `exams/2024/1st-grade/main-booklet-1-languages-natural-sciences.pdf`.
